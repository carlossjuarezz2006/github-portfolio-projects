# Portfolio — Carlos Alberto Juarez

Portfolio profesional de programador full‑stack autodidacta, construido con Next.js 15 + Tailwind CSS.

## Stack

- **Framework:** Next.js 15 (App Router)
- **Estilos:** Tailwind CSS
- **Lenguaje:** TypeScript
- **Deploy:** Netlify

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
